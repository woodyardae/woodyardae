### 🚢 My Fleet of Projects

*   🗃️ **[Bosun PKM Tools](https://github.com/woodyardae/bosun-pkm):** A collection of local-first tools built around standard Markdown vaults, lossless CST parsing, and data portability. Built so personal notes stay durable and accessible over the long haul. 🌿
*   🍳 **[Galley](https://github.com/woodyardae/galley):** An offline-first recipe and kitchen development engine. Handles ingredient scaling, baker's percentages, and clean recipe cards without blog ads or tracking bloat. 🥣🥖
*   🛡️ **[Outrigger Protocol (OPS-1)](https://github.com/woodyardae/outrigger-protocol):** A zero-dependency containment harness for autonomous coding agents. It watches your git tree and checks task manifests so an automated tool can't quietly drift outside its assigned boundaries. 🔒🤖
*   ⚖️ **[AP-Multitool](https://github.com/woodyardae/ap-multitool):** A native, air-gapped desktop utility shaped around an experienced paralegal's real workflow. Instant launches, zero cloud uploads, and vector Bates stamping with margins that protect notary blocks and pleading lines. 📄⚡
*   📡 **[Meridian](https://github.com/woodyardae/meridian):** Marine telemetry experiments—parsing NMEA-0183/2000 sentences, computing collision avoidance math (CPA/TCPA), and handling flaky serial connections on the water. 🧭🌊
*   🎙️ **[Aegis-OS](https://github.com/woodyardae/aegis-os):** Exploring Podcasting 2.0 namespaces, live Hive Podping ingestion, and Value4Value audio streams on native Node SQLite. 📻⚡

### 🛠️ How I Like to Build
- 🔌 **Local-first by default:** If a tool doesn't strictly need a server, it shouldn't have one.
- 📦 **Zero unnecessary baggage:** A single-file script or native binary that compiles cleanly beats a 300MB bundle every time.
- 🧰 **Fix real papercuts:** Software should respect your time, your hardware, and your data.
