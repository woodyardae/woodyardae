### 🛠️ How I Like to Build
- 🔌 **Local-first by default:** If a tool doesn't strictly need a server, it shouldn't have one[cite: 2, 4].
- 📦 **Zero unnecessary baggage:** A single-file script or native binary that compiles cleanly beats a 300MB bundle every time[cite: 2, 3].
- 🧰 **Fix real papercuts:** Software should respect your time, your hardware, and your data[cite: 2, 4].
